# Portfolio image provenance

These images are viewport captures made on September 11, 2026 from the public website URLs listed in `src/data/portfolio.ts`. They are used as linked visual references for work described by Dev By Design.

The captures represent the sites at the time of capture and may include work changed by other teams since Dev By Design’s engagement. Portfolio descriptions identify earlier-version work where known.

Z1 Consultant returned HTTP 403 to the automated browser, so `z1-consultant.svg` is an original abstract CRM dashboard illustration rather than a website screenshot.
